NORTHAUTH - DEPLOY NO RENDER

1. Substitua os arquivos do seu repositório pelo conteúdo deste ZIP.
2. Faça commit/push na branch main.
3. O Render deve iniciar um novo deploy automaticamente.
4. Abra:
   https://northauth.onrender.com/
5. O painel aparecerá e pedirá usuário e senha.
6. Primeiro acesso (se Data/users.json ainda não existir):
   Usuário: admin
   Senha: North@123

Health check:
https://northauth.onrender.com/api/health

IMPORTANTE:
- Mantenha NorthAuth__ApiKey no Render com a mesma chave usada pelos clientes.
- O projeto usa JSON em Data/. O filesystem do plano gratuito pode ser efêmero; para produção use persistência/banco.
