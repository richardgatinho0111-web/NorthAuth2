NORTH AUTH - KEYAUTH STYLE COMPLETO + CREDENCIAIS

Mantém o painel, login multiusuário, licenças/keys, aplicações, ban/reset/delete e o layout dark inspirado em painéis de autenticação.

NOVA FUNÇÃO:
- Credenciais da aplicação diretamente no Dashboard.
- Nome da aplicação, ID, Account Owner ID, Client Secret e versão.
- Botão Mostrar/Ocultar Client Secret.
- Botões para copiar cada credencial.
- Regenerar Client Secret: cria e salva um novo secret no Data/apps.json.

EXECUÇÃO:
1. Rode INICIAR.bat.
2. Abra http://localhost:5000
3. Login inicial, se users.json ainda não existir: admin / North@123

ATENÇÃO: ao regenerar o Client Secret, o secret anterior é substituído.
